# astrbot_plugin_english_tutor · 英语私教

AI 英语私教插件：陪你说英语、纠错、后台自动记录学习数据、每天生成练习。**默认零注入、纯后台记录**，所有注入均可开关。

当前版本：`0.6.3`

收藏句子、收录单词和每日练习可与 `astrbot_plugin_lingxi_gpt_sovits` 联动生成 WAV 音频；WebUI 支持播放、候选音频试听与批量补齐。音频文本按条目请求，文本清洗、语言识别和切分设置沿用语音合成插件。

## 功能

- **后台自动记录（核心）**：自动检测英文对话（滑动窗口统计，全程中文闲聊时零额外开销、零注入），英语模式期间的对话自动按日期存档；教练纠正错误 / 你收藏句子生词时通过工具实时记录；每满 N 轮（默认 10）后台再用模型兜底提取一遍。重复错误自动合并计数。
- **英语模式（可选）**：可注入一段简短的教练提示词（默认关闭），注入位置可选"临时用户消息末尾"（温和、不易带偏人设）或"系统提示词末尾"；也可注入学习档案摘要（近期错误、收藏句子、到期复习）。两者独立开关，都不写入对话历史。
- **自然语言测验**：聊天中直接说"考考我 / 问我几句 / 考我英语"，AI 会自动调用测验材料工具获取到期条目和近期收藏，一轮一题地考你（无需命令、无需注入）；答完说"记住了/忘了"自动调整复习间隔。
- **错误日记**：同类错误重复出现合并计数，注入摘要时会提醒 AI"你 X 月 X 日也犯过"。
- **重点句子 / 单词收藏（带学习情境）**：收藏时自动附带当时的几轮对话作为"学习情境"，每条记录都有来龙去脉；教练收藏句子时会顺手写一段 3~4 句的示例对话展示用法，AI 一键填充也能自动补全（填充提示词可在配置里自定义）。来源清晰：WebUI 手动加的标"我"，教练记的和提取的标"教练"。
- **轻量复习调度**：单词和错句按遗忘曲线安排复习间隔（1→2→4→7→15→30 天）；说"考我"优先考到期条目；绝不主动发消息打扰。
- **每日定时生成**：每天定时生成句子练习或情景对话，可编辑提示词模板；推送支持文字或本地渲染的精美卡片图（可开关中文翻译）；错过可补跑。
- **模型回退链**：WebUI 里直接勾选模型、可排序（无需手填 ID）；按序尝试，支持超时与重试次数（可为 0）；留空则用当前会话默认模型。
- **WebUI 管理页**：管理句子、错误、单词、每日练习与对话存档；支持手动新增（信息可填可不填）、"AI 一键填充"（按回退链模型自动补全释义/例句/示例对话/使用场景，提示词可配置）、搜索、日期筛选、编辑、删除。

## 命令

| 命令 | 说明 |
| --- | --- |
| /英语开启 · /英语关闭 · /英语自动 | 手动切换 / 恢复自动检测 |
| /英语状态 | 查看模式、笔记本与到期复习状态 |
| /英语注入 | 预览当前会注入的提示词内容（含实时档案摘要） |
| /英语统计 | 学习数据统计卡片图（总量、近 7 天对话、最近句子/单词） |
| /英语绑定 · /英语解绑 | 绑定 / 取消每日练习推送会话 |
| /英语测验 | 让私教现在就考考你 |
| /英语总结 | 立即提取最近对话的学习记录 |
| /每日英语 [要求] | 获取今日练习；可附带要求，如 `/每日英语 商务对话` |
| /英语重写 [要求] | 不满意就重写今日练习；要求可省略，如 `/英语重写 校园场景 来几个句子` |

所有记录随时可查：直接问 AI"昨天咱们学了啥 / 我错了啥 / 今天要学什么"，它会用 `english_lookup` 查询后回答。

## LLM 工具

插件按动作注册六个小工具，便于 `skills_like` 模式按需加载准确参数：

- `english_quiz_material()`：获取测验材料。
- `english_save_sentence(sentence, note, dialog)`：收藏句子。
- `english_log_error(sentence, correction, note)`：记录错误。
- `english_add_vocab(sentence, note)`：记录单词或短语。
- `english_mark_review(sentence, kind, remembered)`：更新复习结果。
- `english_lookup(kind, date)`：查询记录、对话存档或每日练习。

## 配置

在 WebUI 插件配置页设置，全部中文说明。默认状态 = 纯后台记录：不注入任何提示词，不干扰模型人设。想要纠错陪伴体验就打开"注入教练提示词"（可选位置），想要 AI 主动提醒就打开"注入学习档案摘要"。

## 数据

数据存储于 `data/plugin_data/astrbot_plugin_english_tutor/tutor.db`（SQLite）。与长期记忆插件相互独立，互不影响。
